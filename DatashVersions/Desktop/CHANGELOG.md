## [0.1.0] - 2025-06-02

### Added
- Initial release of Datash
- Terminal-based user interface with colorized output
- Gemini AI API integration for intelligent responses
- Natural language processing for command interpretation
- Interactive shell with command history
- Built-in commands (!help, !exit, !clear, !config, !version, !history)
- Direct shell command execution with $ prefix
- Intelligent next-action suggestions
- Database operations support (MySQL, PostgreSQL, SQLite, MongoDB)
- Git command assistance
- Cross-platform support (Windows, macOS, Linux)
- Configuration management via environment variables and config file
- Automatic API key management
- Comprehensive test suite
- Installation script with guided setup
- Platform-specific launchers
