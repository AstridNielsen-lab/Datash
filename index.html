Data Import

CSV to SQLite Import
datash> import csv to sqlite and create a table 
import sqlite3
import csv

# Connect to SQLite database
conn = sqlite3.connect('my_database.db')
cursor = conn.cursor()

# Create table
cursor.execute('''
CREATE TABLE IF NOT EXISTS my_table (
    id INTEGER PRIMARY KEY,
    name TEXT,
    age INTEGER,
    email TEXT
)
''')

# Import CSV data
with open('data.csv', 'r') as csv_file:
    csv_reader = csv.reader(csv_file)
    header = next(csv_reader)  # Skip header row
    
    for row in csv_reader:
        cursor.execute('''
        INSERT INTO my_table (id, name, age, email)
        VALUES (?, ?, ?, ?)
        ''', row)

# Commit changes and close
conn.commit()
conn.close()

FREQUENTLY ASKED QUESTIONS

Everything you need to know about Datash

What is Datash?

Datash is a powerful terminal-based assistant that helps programmers interact with databases, manipulate data, execute shell commands, and manage Git repositories - all with intelligent suggestions and autocompletion powered by Google's Gemini API. It allows you to use natural language to perform complex operations that would normally require remembering specific syntax.

How do I install Datash?

You have two options:

  1. Install from PyPI (Recommended):
    Run pip install datash in your terminal, then verify with datash --version
  2. Install from Source:
    Download the files from our Downloads section, then run pip install -r requirements.txt to install dependencies

You'll also need Python 3.8+ and a Gemini API key from Google AI Studio.

Is Datash free to use?

Yes! Datash is an open-source project released under the MIT License. You can use it freely for both personal and commercial projects. If you'd like to support the ongoing development, consider making a financial contribution through one of the methods listed in the Contribute section.

How does the AI chatbot work?

Datash uses Google's Gemini API to process natural language queries and generate helpful responses. When you type a query or question, it's sent to the Gemini model which interprets your intent and returns appropriate code, explanations, or commands. The AI can handle everything from database operations to Git commands to data processing tasks, all through simple conversational language.

Can I use Datash offline?

Most of Datash's core data processing and shell integration features work offline, but the AI capabilities powered by Gemini require an internet connection to send queries to the API. However, Datash is designed to gracefully degrade when offline, still providing access to local database operations, stored procedures, and previously cached responses.

How can I report bugs or request features?

You can contribute to Datash development in several ways:

  1. Fork the GitHub repository and submit pull requests
  2. Open issues on GitHub for bugs or feature requests
  3. Contribute to documentation improvements
  4. Share your usage examples and tips with the community

We welcome all contributions and actively review submissions from the community.

How do I configure Datash?

Datash creates a configuration file at ~/.datash_config.json when you first run the application. You can modify settings by:

  1. Using the built-in commands: !config set key value
  2. Directly editing the configuration file

Key settings include API URL, history file location, maximum history entries, and display preferences.
